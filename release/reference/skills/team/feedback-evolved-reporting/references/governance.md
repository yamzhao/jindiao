# Evolution governance

Allowed scope: Markdown organization, section guidance, citations, uncertainty wording, missing-data disclosure, and readability. Forbidden scope: `config/risk-*`, risk engine code, score thresholds/bands, Tianyancha source priority, fallback authorization, `is_mock`/`source_status` semantics, accepted-Finding Evidence requirements, credentials, Authorization headers, or redaction behavior.

A candidate is not active merely because it exists or passes automated evaluation. Activation and rollback both require an identified human approver and an auditable metadata record.

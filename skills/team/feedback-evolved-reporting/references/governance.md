# Reporting Demo governance

Allowed change: repeat an already disclosed appendix gap beside its fixed mapped section using `section_and_appendix`. Feedback text is background only. Risk rules, thresholds, decision bands, evidence, source priority, Mock marking, credentials and redaction are outside the policy whitelist.

Use actual nine-case rendering and output inspection, never prefilled scores or the number of syntactically valid cases. Passing evaluation creates an immutable awaiting_approval candidate. Only an explicit local apply command changes active state; reset restores baseline and increments revision. A local reason and timestamp are receipts, not authenticated approver identity or complete audit history.

The Demo is for one local process and one operator. File hashes detect corruption and inconsistency; they do not protect against a malicious administrator who controls all files. Production authentication, shared storage and distributed publication are deferred.
